En este repositorio agregare todo el material realizado en mi tercer semestre de ingenieria y lo realizado.

Diseño de clases en el aula:
Diseñar tres clases en el aula, incluyendo tanto la descripción UML que hicieron en la libreta como el proyecto completo.

Encapsulación y memoria:
Realizar un programa que tenga 2 clases. Deben estar bien encapsuladas (con atributos private, y métodos get y set). Cada clase debe tener 3 atributos: 1 en memoria estática y 2 en memoria dinámica (punteros). Se debe usar en el main de manera funcional.

Sobrecarga de operadores:
Crear una clase con 3 atributos privados (implica crear sus métodos get y set). Deberá desarrollar la sobrecarga de los operadores binarios: +, -, *, / (puede hacerlo como funciones miembro o como funciones amiga no miembro, basándose en el ejemplo de Luis Joyanes). También deberá desarrollar la sobrecarga de los operadores de flujo << y >> (recuerde los ejemplos de Deitel y Deitel). Usar todos sus operadores en la función main para demostrar que funciona correctamente.

Herencia simple y múltiple:
Realice dos programas con todos los conceptos de herencia (al finalizar recuerde subir todos sus archivos en un .zip):

Un proyecto que tenga tres clases con herencia simple de manera lineal.

Un proyecto con herencia múltiple, con tres clases en formación de diamante.

Polimorfismo:
Realizar un programa que desarrolle el polimorfismo. Crear una clase con 3 atributos y 4 métodos virtuales (esta será la clase padre o superclase). Luego, crear 3 subclases o clases hijo, haciendo la definición de los métodos virtuales. Con ello poder crear instancias de las clases.

Proyecto Final:
Requisitos de programación: Debe realizar su proyecto en archivos .cpp y .h. Debe hacer uso de las clases y realizar los get y set necesarios, sobrecargar al menos 8 operadores, crear apuntadores de punteros a clase, realizar herencia para especializar al menos dos clases, crear polimorfismo y crear vectores de objetos.
Requisitos del sistema: Deben crear un sistema que tenga un menú principal y permita lo siguiente (después de cada proceso debe regresar al menú): dar de alta un producto, servicio o registro; realizar una búsqueda dentro del vector y desplegar la información del registro localizado; dar de baja un producto, previa búsqueda y solicitando una confirmación; y tener un algoritmo que despliegue todos los datos registrados en el vector.roceso anterior regresar al menú principal.
