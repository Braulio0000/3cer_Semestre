# 3cer_Semestre
En este repositorio agregare todo el material realizado en mi tercer semestre de ingenieria y lo realizado.
Programación orientada a objetos:
1- Diseñar tres clases en el aula, tanto su descripción UML que hicieron en la libreta como el proyecto completo.
2- Realizar un programa que tenga las siguientes caracteristicas:
Debe crear 2 clases
Deben estar bien encapsuladas (get, set, y private)
Deben de tener: 3 atributos; 1 en memoria estatica y 2 en memoria dinamica (ptr)
Usarlo en el main de manera funcional.
3-Crear un clase con las siguentes caracteristicas:
Debe contener 3 atributos privados. Implica crear sus  get y set.
Debera desarrollar las sobrecarga de los operadores binarios: +,-,*,/ . Puede hacer como funciones miembro o como funciones amiga no miembro. Pueden basar su programa en el ejemplo de Luis Joyanes (el de Binario)
Debera desarollar las sobrecarga de los operadores de flujo << y >>, recuerde los ejemplos vistos en el libro de Deitel y Deitel
Usar todos sus operadores en la funcion main, para demostrar que funciona correctamente.
4-Realice dos programas con todos los conceptos de herencia simple, herencia múltiple al finalizar suba su ejemplo. Recuerde subirlo todos sus archivos en zip.
1) un proyecto que tenga tres clases con herencia simple de manera lineal
2) Un proyecto con herencia múltiple, con tres clases en formación de diamante.
5- Realizar un programa que desarrolle el polimorfismo con las siguientes caracteristicas:
Crear un clase con 3 atributos, y 4 metodos virtuales (esta será clase padre o superclase)
Crear 3 subclases o clases hijo, haciendo la definicion de las metodos virtuales. Con ello poder crear instancias de las clases.
6-Proyecto Final:Requisitos

1) Debe de contener el uso de las siguientes estructuras de programación: 
Hacer uso de las clases
Sobrecargar al menos 8 operadores
Crear apuntadores de punteros a clase 
Realiza herencia para especializar de al menos dos clases
Crear polimorfismo
Crear vectores de objetos 
Realizar los get y set necesarios de su clase
Debe de realizar su proyecto en archivos .cpp y .h 
2) Deben de crear un sistema donde se pueda hacer lo siguiente:
Dar de alta un producto/servicio/agende o cualquier cosa 
Búsqueda dentro del vector y desplegar la información del registro localizado 
Dar de baja un producto, previa búsqueda y solicitar una confirmación 
Crear un algoritmo que me despliegue todos los datos registrados en el vector
Después de cada proceso anterior regresar al menú principal.
